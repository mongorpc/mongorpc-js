# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-01-05

### Added
- **Admin SDK**: Full `AdminClient` for schema and index management using Admin Key.
- **Rules Engine Support**: Handling for permission errors and data-driven rule contexts.
- **Change Streams**: Real-time `onQuerySnapshot` support.
- **Filters**: Advanced filtering (map-based and builder-based).

### Changed
- **Client API**: Streamlined connection and instantiation interface.
- **Types**: Improved strict typing for Documents ($set, $inc, etc.).

### Fixed
- **Build Issues**: Resolved TypeScript compilation errors.
